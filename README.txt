วิธีติดตั้ง (ฟรี)

ตัวเลือก A: Netlify Drop (ง่ายสุด)
1. แตกไฟล์ zip นี้
2. เปิด https://app.netlify.com/drop แล้วลากโฟลเดอร์ทั้งโฟลเดอร์ไปวาง
3. จะได้ลิงก์ https://xxxx.netlify.app

ตัวเลือก B: GitHub Pages
1. สร้าง repo ใหม่ อัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้
2. Settings > Pages > เลือก branch main > Save

เปิดลิงก์ในมือถือ:
- Android (Chrome): เมนู ⋮ > "ติดตั้งแอป" / Install app
- iPhone (Safari): ปุ่มแชร์ > "เพิ่มไปยังหน้าจอโฮม"

หมายเหตุ: ต้องเปิดผ่านลิงก์ https เท่านั้น (ดับเบิลคลิกไฟล์ในเครื่องจะใช้ออฟไลน์/ติดตั้งไม่ได้)
ข้อมูลเก็บในเบราว์เซอร์ของเครื่องนั้น ไม่ซิงก์ข้ามเครื่อง
